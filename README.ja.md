# DIMENSION — Bitcoin Interactive Space

[公開サイト](https://pythonddd.github.io/dimension/)

## 4つの操作空間と4つのゲーム

| 宇宙 | 専用機能 | ミニゲーム |
| --- | --- | --- |
| ワームホール | 慣性のあるドラッグ・矢印 / WASD操縦、重力レンズ、浮遊量、ブースト、航行距離の演出 | **SATS SURFER**：60秒で金色の輪を回収。障害物・シールド・コンボ |
| サトシの銀河 | 実際の最近のブロックを選択し、プール・取引数・重量・時刻を表示。エクスプローラーへのリンク | **LIGHTNING LINK**：容量制約のある経路を5問。最小コストと比較して採点 |
| テセラクト | XW / YW / ZWの4次元回転、投影距離、自動 / 手動の切替 | **BLOCK BUILDER**：容量100に取引を選ぶ3問。最大手数料の組み合わせと比較 |
| 2017 | 365日分の終値を日付選択・速度切替で再生。日付に連動する空、再生価格に連動する音 | **HASH ECHO**：光と音の順番を覚える12ラウンド。音なし・キー1–4でも操作可能 |

ゲームはローカルのシミュレーションです。実際の送金・マイニング・Lightningチャネル・報酬ではありません。最高記録は端末内に保存します。時間制のゲームはタブを離れると停止し、戻ったら再開ボタンで続行します。

## 操作

- **1–4**：宇宙を切替。各宇宙のパネルからゲームを開けます。
- **音を開始 / M**：音声を開始・停止。設定から音量変更と確認音の再生ができます。
- **Z**：操作表示を隠す / 戻す。**F**：対応ブラウザで全画面。
- **Space**：背景を一時停止。飛行ゲームでは操作領域にフォーカスがあるとき一時停止。
- スマホの **☰**：ネットワーク・市場・ラボ・設定へ。
- **撮影**：現在の宇宙をPNGで保存。**WARP**：次の宇宙へ。自動周遊は90秒ごと。

大きな紹介見出しは削除し、中央を操作領域にしています。観測データは開閉可能です。

## 音と浮遊感

音声コンテキストはユーザー操作で生成・再開し、実際の再生状態を表示します。休止状態を再生中と表示しません。各宇宙の和音、左右に広がるパッド、風音、ディレイ、操作・ゲーム効果音をWeb Audioで合成します。Hash Echoでは環境音を下げ、背景のアルペジオを止めます。

WebGL・Canvasで奥行きの違う星やリングを描き、視点が慣性を伴って追従します。浮遊量、動きを抑える設定、自動画質、省電力を選べます。ゲーム中は背景描画を停止。非表示タブでは描画・音・定期通信を休止します。WebGLが使えない場合はCanvasへ切り替えます。

## データと既存ツール

ブロック、メモプール、推奨手数料、半減期、補助金・理論発行量、BTC/USDチャート、ETH/SOL、通貨換算、実際のSHA-256を使う教材、取引のテキスト照会、達成記録を引き続き利用できます。

- [mempool.space](https://mempool.space/docs/api)：ネットワーク観測とBTC/JPY。
- [Coinbase Exchange](https://docs.cdp.coinbase.com/exchange/introduction/welcome)：USD価格とローソク足。
- [Bitcoin Core](https://github.com/bitcoin/bitcoin)：補助金・半減期などの規則。
- `data/history-2017.json`：UTCの2017年365日分。取得元と取得日時を記録した履歴です。

通常60秒ごとに取得し、ブロックはWebSocketでも受信。古い値や失敗を明示し、架空の価格で補完しません。進行中のローソク足を含む場合があります。メモプールは取得先ノードの観測値です。残り日数は10分/ブロックの目安。手数料は推定。理論発行量はGenesisを含む補助金の累計で、実際の流通量ではありません。

軌道上の配置、星、航行距離は演出です。OP_RETURNは文字列として表示し、P2PKHテキストは推定表示。外部のHTMLやスクリプトを実行しません。採掘パズルは単一SHA-256の教材で、実際のBitcoin採掘ではありません。

## 公開・開発

GitHub Pagesは **main / (root)** から配信します。外部ホスティング、APIキー、ウォレット接続、Secrets、実行時パッケージは不要です。ローカルではHTTPSまたはlocalhostで配信してください。`file://`は対象外です。

Node.js 20以上：

```sh
npm test
npm run check
npm run build
```

`dist/`は任意の配信用出力。検証ワークフローはテスト、構文・参照整合性、ビルドを実行します。旧版はコミット `79a40d724154c10a30081a90d8201696cf9ce6ae` と `archive/original-2026-10-20` に残っています。

## 検証範囲

28件の自動テストで既存の計算・データ処理、飛行の衝突判定、経路の解、ブロックの最適解、記憶ゲームの状態、音声の開始・休止・失敗を検証しています。APIを置き換えたDOM操作検証では、専用操作画面、全ゲームのラウンド進行、停止・再開・再挑戦、記録保存、既存ツール、音声UIを確認しました。シェーダーはEGLで実際にコンパイル・描画。オフラインのWeb Audio実装で4種類の非無音ステレオ波形と消音を確認しています（その実装ではコンプレッサーは素通し）。

**実ブラウザのレイアウト、スマホのGPU性能、実機での音声再生・聴感は未確認です。** DOMや波形の検証は、個々のブラウザの自動再生制限を検証するものではありません。

設定・観測キャッシュ・達成記録・ゲームスコアはlocalStorageに保存します。外部データは各提供元へ直接通信するため、停止・制限・CORS・地域制限の影響を受ける場合があります。
